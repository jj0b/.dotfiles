# Dotfiles

## Flake platforms

`nix/flake.nix` installs one shared tool list on two systems. A change to installed tools has to account for both.

- macOS is `darwinConfigurations.zen` (nix-darwin). Apply with `darwin-rebuild switch --flake ~/.dotfiles/nix#zen`.
- Linux, including Omarchy, is home-manager: `homeConfigurations.jason` (x86_64) and `homeConfigurations.jason-aarch64`. Apply with `home-manager switch --flake ~/.dotfiles/nix#jason`.

When adding or removing a tool:

- Put a tool used on both platforms in `commonPackages`.
- Put a Linux package that stands in for a Homebrew formula in `linuxPackages`.
- Keep Homebrew formulae, casks, Dock settings, and other `system.defaults` in the darwin configuration only.
- Leave `vite-plus` on Homebrew until nixpkgs has a package. Do not invent a nixpkgs name for it.
- Keep `install.sh` as the stow step. Do not make it install packages or Node.

The Linux profile is user `jason`, home `/home/jason`. Do not retarget that unless asked.

Homebrew is Nix-managed. Leave `mutableTaps = false`, `onActivation.autoUpdate = false`, and `nix-homebrew.enableZshIntegration = false`. Do not run `brew update`, `brew tap`, or the fixes `brew doctor` suggests. Move the lock with `nix flake update ./nix`, review `nix/flake.lock`, then apply with `dr`.

After editing the flake, evaluate both outputs from `nix/`:

```bash
nix eval .#darwinConfigurations.zen.config.system.primaryUser
nix eval .#homeConfigurations.jason.config.home.homeDirectory
```

## Stow

Top-level packages are `ghostty`, `git`, `lsd`, `nvim`, `tmux`, and `zsh`. `install.sh` stows those and nothing else. Do not stow `nix/`. A flake path that is a symlink does not work.

Those stowed files are the same on macOS and Linux. Put platform-specific system setup in the flake. These existing bits are macOS-only and should stay guarded or untouched unless asked: tmux `bind o` runs `open`, Ghostty sets `macos-option-as-alt`, `zsh/.zshrc` defines `dr`, and `git/.gitconfig` points the credential helper at a macOS path.

## Shell

`zsh/.zshrc` runs `brew shellenv` only when `/opt/homebrew/bin` is not already on `PATH`. Do not add another Homebrew `PATH` prepend. Cursor starts a login shell to capture the environment, then starts another, and an unconditional prepend duplicates `/opt/homebrew/bin`.

Leave the Vite+ source line at the bottom of `zsh/.zshrc`. `zsh/.p10k.zsh` is generated by `p10k configure`. Do not hand-edit it.

## Neovim

Neovim is LazyVim. Add plugins in `nvim/.config/nvim/lua/plugins/`. Put options and keymaps in `lua/config/`. Language extras live in `lazyvim.json`. When a plugin spec changes, update `lazy-lock.json`.

## Git

`git/.gitconfig` is the personal identity. Repos under `~/Code/Anthos/` use `git/.gitconfig-anthos` through `includeIf`. Do not merge those identities. Do not commit tokens or credentials.

## Do not commit

Nix `result` symlinks, `tmux/.config/tmux/plugins`, tmux resurrect data, and `.nvimlog`.
